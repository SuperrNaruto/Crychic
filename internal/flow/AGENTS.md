# Flow

修改会话或业务流程前，读取 [会话详情](../../docs/agent-reference/flow.md) 的对应小节。
修改任何用户可见内容时，必须读取其中的界面与文案规则；发现与身份匹配另读 [发现详情](../../docs/agent-reference/discovery.md)。

## 会话与写入

- 会话 ID 跨重启随机；`Choose` / `Answer` 同时核验用户和聊天，每个会话的步骤串行执行。
- 回调动作在所有 handler 间唯一，数据不超过 64 字节；受保护写按钮只接受当前屏幕的确认票据，适用动作见详情。
- 先在步骤锁内消费可确认目标，再执行一次写入；重复或陈旧按钮不得重复写入，也不得覆盖成功回执。
- 批量下载只在一个后台 worker 中串行调用 MoviePilot API；Follow 只读进度。停止只阻止后续提交，当前请求等结果，不暂停或删除已创建的任务。
- 流式资源搜索按代次隔离，按钮绑定资源身份，不可因排序、过滤、返回或重搜换成另一资源；显示序号按当前列表位置从 1 起；完整终态前只读浏览。详情固定已选资源，最终目标改变须重选；本地取消与退出关闭流并等待 worker，不宣称上游站点请求即时停止。
- 提交中的原消息只接受当前批次的进度与停止；完成或停止后恢复终态导航。应用退出须等待 worker，重启不重放不确定写入。
- 失败读取保留上下文，只重试失败的读取。未知写结果不能重试：订阅创建/取消指向 `/subscribe`，下载创建/删除指向 `/tasks`，暂停/恢复要求刷新。
- 直接请求保留不可变终态回执到 TTL；从列表发起的请求保留返回列表的导航。不可把写操作或后台轮询当作可重放的读取按钮。
- 订阅按钮携带订阅 ID，不用列表下标；暂停、恢复、取消及详情读取前核对来源、媒体 ID、类型、季、剧集组与原创建时间。
- 核验失败或身份更换只给 notice，不写入；客户端预检不能声称提供后端原子 compare-and-write。
- 订阅编辑只提交明确变动的条件，写前消费草稿和当前票据；不得覆盖进度事实、重放未知写入或从返回恢复已消费的确认。选项和输入代次不随返回复用。
- 未提交的编辑草稿离开时保护改动，后台冲突保留草稿并重新确认；已提交的结果摘要只读，不得转换回可写草稿。核对值一致不代表能追认上次请求成功，敏感条件仅比较不展开。
- 单订阅立即搜索与停止各自明确确认，写前消费当前目标；只跟踪本地确认新建的单订阅批次，不接管后台合并批次。停止前重核订阅复合身份、批次范围与创建时间；未知写入只读核对，停止受理不等于已停止，也不撤销已提交下载。本地交互取消的 Follow 读取不覆盖当前屏幕，真实读取失败仍需撤下控制入口。
- 前进保存屏幕与状态，同级操作替换屏幕；返回恢复对应状态，状态变化后的订阅列表重新读取。
- 更正片名保留下载意图，显式前缀可覆盖；首页和新发现列表清除前一标题的意图，返回恢复原标题状态。
- 唯一结果或指定季可以跳过选择，但不跳过最终确认；specials 不自动选中。
- 同系列状态由订阅、下载与媒体库读取共同决定，任一所需读取失败即未知且不可勾选；补齐写入前逐部核对订阅，不持久化库存。
- 剧集组只用于 TMDB 剧集，空组不列出；剧集组下媒体库、下载、只追新集、资源搜索、搜索站点、洗版和多选季不按标准分季套用，重新选片清除剧集组。
- 条件找片只用 TMDB，选项与官方探索页一致，作为下界传给 MP；翻页按身份去重且不改已有编号。演职人员作品和条件找片结果按榜单条目处理，非 TMDB 来源按标题对上，对不上时说明。
- 订阅历史逐页从 MP 读取，按历史 ID 去重并保持已有编号；无媒体身份的记录只计数不列出，不用本地历史库补全或扩大首屏冒充完整历史。
- 媒体详情和媒体库状态仅作补充；失败允许继续确认，但显示未知，不能说成未入库。
- 整理百分比只给唯一匹配且仍在运行的文件，按媒体、季、集、下载 hash 与实例匹配；全局或无法唯一对应的进度不显示，进度读取失败保留逐文件状态。
- 下载暂停与恢复分别确认，确认码携带方向并绑定当前票据；写前重读任务，已消失、已处于目标状态或实例不唯一时不写。实例不唯一的任务不提供暂停、恢复和删除；回执只给只读的「查看任务」。
- 组合筛选只在已有结果中进行，不访问站点；同字段多选取或、字段间取且，空值作为「未知」选项；选项在打开字段时固定，新搜索清空条件，缺集方案只取当前筛选内的资源。
- 缺集方案只用完整搜索中的可信单季范围，确认前重读库存与季总数；变化先更新预览重新确认。必须展示重复、重叠、缺口和未知大小，不承诺裁剪整包文件或全局最优。
- `*flow.UserError` 才能直接展示；其他错误使用通用提示，敏感响应仍受根隐私规则约束。

## 界面与文案

- 输出 `flow.Text` 语义块，不在 flow 字符串内放平台 HTML；适配器负责渲染与转义。
- 普通会话消息都以 `Heading` 开头；卡片、表格、列表、注释和小字使用既定语义块。
- 选择按钮只放编号或短操作名，不放 emoji、媒体标题或事实；URL 出口按详情中明确列出的作用域处理。
- 按钮行顺序固定为选择、切换、后续操作、导航；只显示一个返回入口。破坏性确认只有确认操作与返回。
- 请求以取消结束，浏览使用首页/关闭；保留普通列表与 `Brief` 条目的不同布局。
- 机器人语气、emoji 与颜文字白名单、事实中性和安全文案要求以详情为准，不自行泛化或缩减。
- 文案正面陈述结果与核对位置，不用「会 X 而不会 Y」「不代表／不等于 Z」等否定式免责句；安全含义改用正面说法保留，见详情。
- `Reply.Notice` 只闪提示，不编辑原消息；他人的点击不能改变请求者屏幕。
- 文字和按钮一起计入分页预算；省略项目必须明确说明，并保留完整汇总数。

## 相关边界

- 改订阅、下载或媒体库接口时，读取 [MoviePilot 详情](../../docs/agent-reference/moviepilot.md)。
- 改通知回执或原生通知展示时，读取 [通知详情](../../docs/agent-reference/notifications.md)；回执只说明由 MP 按设置通知，不承诺到货提醒。
- 改输入、Follow 或投递语义时，读取 [Telegram 详情](../../docs/agent-reference/telegram.md)；投递重试不得重跑业务步骤。
