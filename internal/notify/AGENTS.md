# Notifications

修改通知、游标、持久化、迁移、完成或停滞判断前，读取 [通知详情](../../docs/agent-reference/notifications.md)。
修改通知文案时，同时读取 [界面与文案规则](../../docs/agent-reference/flow.md#界面与文案)。

- 先原子保存状态，再发送通知；保留可漏发但不重放的取舍，失败发送不自动补发。
- 状态转换保留未触及字段；必要写入在状态锁下串行，状态未变不重写。
- 成功转移按完成日期及该秒所有已见 ID 推进游标；边界秒不完整不能提交 checkpoint。
- 首次轮询建立基线，空的已初始化游标也持久化；旧 watermark 迁移不得丢失请求、pending 或 digest。
- 订阅 watch 身份包含 row ID、媒体来源、媒体 ID 与季，不能按可复用的 row ID 合并授权或状态。
- 收集与结算前刷新订阅范围及 `best_version`；失败读取不推进游标或清除 pending，等待只读重试。
- 订阅关闭不代表文件已入库，不能立即结束 watch；保留订阅与下载不同的关闭、grace 与完成语义。
- 同媒体同季的 pending 到货一起结算，按 library wait 预算等待整组可见，不能只检查一个 watch；整组每个目标都满足完成条件时才宣称完成。
- 每个下载独立跟踪；是否合并为一条消息由通知结算规则决定，不由 watch 数量决定。
- `Held` 与下载实际到货分开保存；既有库存不能吞掉替换下载的后续通知，升级不能凭旧库存宣称全部洗版。
- quiet、library wait、stall 与周汇总的关闭值、首次基线、重启及去重规则按详情保留。
- 只保存 `src` 的文件名，最多保留既定数量的资源样本；不保存服务器路径或敏感原始记录。
- 频道目标替代请求者投递，不暴露请求者身份、不回退原聊天；空目标保留原投递方式。
- 无进展不等于死种；排队与下载中的上游状态可能混用，停滞提醒不能断言原因。
- 核对转移、库可见性和下载字段时读 [MoviePilot 详情](../../docs/agent-reference/moviepilot.md)；改 fake 时先读 [E2E 规则](../../e2e/AGENTS.md)。
